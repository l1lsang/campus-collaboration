# 기능 상태

## Phase 1 구현

- 공개 랜딩, 공개 프로젝트 탐색: 최근 공개 프로젝트 최대 100개에 대해 키워드·프로젝트 유형 필터 제공.
- 이메일 인증 코드 회원가입/로그인, 로그아웃, 인증 보호 라우트.
- 기본 프로필 온보딩과 수정, 공개/비공개 선택, 대학 목록 DB 조회.
- 확인된 계정 이메일을 기반으로 한 학교 인증: 학교 목록은 제공하되 실제 사용 도메인은 운영 검증 후 등록.
- 개인 대시보드, 내 프로젝트 목록, 공개/비공개 프로젝트 생성과 상세.
- 팀장 초대 링크 발행·취소, 다른 계정의 수락, 팀원 목록. 이메일 자동 초대·특정 수신 계정 지정·팀원 제거/탈퇴는 다음 범위.

## 미구현

- 역할 분담, 업무·칸반·활동 기록, 지연 및 업무량 안내, 익명 피드백, 부담 설문.
- 모집글 및 지원·승인, 아이디어, 프로젝트 리부트, 대학·전공 매칭 필터.
- 리서치 풀, 크레딧, AI 보고서·아카이브, 관리자 UI, 알림, 첨부파일.
- 별도 학교 이메일로의 인증, 교차 계정 병합, 학생증 제출, 운영 배포.
